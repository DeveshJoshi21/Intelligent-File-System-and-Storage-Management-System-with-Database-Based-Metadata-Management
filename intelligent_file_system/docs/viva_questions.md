# Viva questions
**Why SQLite?** Embedded relational DB with transactions and no separate server.
**Why indexes?** Speed up filename, extension, size and hash lookups.
**What is UPSERT?** Insert, or update the row when a unique-key conflict occurs.
**Why SHA-256?** Content fingerprint; size alone cannot establish equality.
**What is internal fragmentation?** Unused bytes in the final allocated block.
**Is Storage Lab physical disk truth?** No, it is a clearly labelled educational simulation.
**Does it delete duplicates?** No; the application is read-only.
